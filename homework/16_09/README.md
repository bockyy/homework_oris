# Чат на сокетах (TCP)

Формат сообщения (заголовок 8 байт + данные):
1. Команда (4 байта) — текстовая команда в кодировке UTF-8.
2. Длина данных (4 байта) — беззнаковое целое число, упакованное через `struct.pack('!I')`.
3. Полезная нагрузка — байты сообщения переменной длины (ограничено константой MAX_MESSAGE_SIZE).

Поддерживаемые команды:
- `JOIN` — регистрация клиента на сервере. Тело: никнейм.
- `TEXT` — рассылка текстового сообщения. Тело: текст сообщения.
- `LIST` — запрос текущего списка пользователей онлайн. Тело пустое.
- `QUIT` — штатное отключение от сервера. Тело пустое.
