# Task Manager (PyQt6)

Десктопное приложение для управления и структурирования задач с графическим интерфейсом на библиотеке PyQt6.

Проект разработан в рамках практического задания по изучению виджетов, компоновок (layouts) и событийной модели Qt.

## Реализованный функционал

### Базовые возможности
- Ввод наименования задачи (`QLineEdit`) и подробного многострочного описания (`QTextEdit`).
- Выбор приоритета задачи: *Low*, *Medium*, *High* (`QRadioButton`). По умолчанию активен *Medium*.
- Дополнительные флаги: *Important*, *Notification*, *Favorite* (`QCheckBox`).
- Генерация карточки задачи и вывод данных в интерфейс приложения.
- Сброс полей ввода формы к исходным значениям (кнопка *Clear task*).

### Дополнительный блок (Бонусный функционал)
- **Хранение данных в памяти:** задачи сохраняются во внутренний список `self.tasks` в виде словарей.
- **Фильтрация на лету (`QComboBox`):** возможность фильтровать отображаемый список по категориям *All*, *Low*, *Medium*, *High* без потери данных.
- **Удаление задач:** кнопка *Delete task* удаляет последнюю созданную задачу из памяти и обновляет экран.
- **Динамический счетчик:** отображение актуального количества существующих задач (*Task Count*).
- **Индикатор статуса:** отслеживание состояния приложения (*Status: Ready*, *Task created*, *Task deleted*, *Nothing to delete*).

## Архитектура

- Окно построено на базе `QMainWindow` с единым `centralWidget`.
- Разметка адаптивная: использованы вложенные компоновки `QVBoxLayout` и `QHBoxLayout` без жесткого позиционирования (`setGeometry`).
- Применена архитектура с единым источником состояния: метод `render_tasks()` централизованно перерисовывает интерфейс при любых мутациях данных (добавление, удаление, смена фильтра).
