1. Инструкция по запуску:
python server.py для запуска сервера
python client.py для запуска клиента
сначала запускается сервер, затем любое количество клиентов в разных терминалах.
2. /add <текст>, /list, /done <номер>, /delete <номер>, /quit
3. Главный поток сервера слушает порт и находится в цикле ожидания подключений server_sock.accept()
Как только клиент подключается, сокет клиента передается в отдельный рабочий поток threading.Thread(target=handle_client, args=(client_sock, addr))
Метод .start() запускает обработку клиента в фоновом режиме, а главный поток немедленно возвращается к ожиданию следующего клиента accept()
За счет этого блокирующие операции чтения (recv) одного клиента не тормозят и не блокируют работу других клиентов
